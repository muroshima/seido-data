# 文化財の保存修復に関する助成のご案内（文化財保護・芸術研究助成財団）

取得元の利用規約により本文は掲載せず、制度の情報だけを取り出しています。正確な内容は `url` のページで確かめてください。

## 対象者

都道府県または市町村の補助対象事業として修理を予定している文化財

## 支援内容

美術工芸品、建造物文化財、有形民俗文化財の保存修復

## 期間

令和7年度

## 利用方法

申請書類を提出し、審査を経て助成
