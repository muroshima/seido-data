# 子どもの手当・医療費助成

取得元の利用規約により本文は掲載せず、制度の情報だけを取り出しています。正確な内容は `url` のページで確かめてください。

## 対象者

扶養親族

## 支援内容

市民税の所得割課税額の基準算出方法

## 期間

平成25年度

## 利用方法

扶養親族の年齢と人数をもとに、区分Cまたは区分Dの基準額を計算し、市民税の所得割課税額と比較して区分を判断します。
