# 雨水活用設備（雨水貯留槽・雨水浸透桝）設置費補助金のご案内

取得元の利用規約により本文は掲載せず、制度の情報だけを取り出しています。正確な内容は `url` のページで確かめてください。

## 対象者

住宅、アパート、店舗、工場等の建築物を所有または占有し、その建築物に雨水活用設備を設置する方

## 支援内容

雨水貯留槽・雨水浸透桝の設置費用を補助

## 期間

予算が無くなり次第終了

## 利用方法

設置完了後に申請（設置完了年度内）
