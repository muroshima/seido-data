# 高齢者補聴器購入費助成について

取得元の利用規約により本文は掲載せず、制度の情報だけを取り出しています。正確な内容は `url` のページで確かめてください。

## 対象者

市内在住の65歳以上で、身体障害者手帳を持たず、医師の診断書を受けた高齢者

## 支援内容

補聴器本体と付属品の購入費を20,000円まで助成
