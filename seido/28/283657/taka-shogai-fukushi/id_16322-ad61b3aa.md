# 特別障害者手当

取得元の利用規約により本文は掲載せず、制度の情報だけを取り出しています。正確な内容は `url` のページで確かめてください。

## 対象者

重度障害者で日常生活に特別な介護が必要な20歳以上の人

## 期間

申請月の翌月から資格喪失月まで

## 利用方法

申請時に身体障害者手帳・医師の診断書・マイナンバー書類等を提出
