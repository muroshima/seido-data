# 産後ケア事業のご案内

取得元の利用規約により本文は掲載せず、制度の情報だけを取り出しています。正確な内容は `url` のページで確かめてください。

## 対象者

市内在住、出産後1年未満のお母さんと赤ちゃんで育児に不安がある方

## 支援内容

助産師による自宅訪問や施設での育児指導

## 期間

出産後1年（お子様の誕生日の前日まで）

## 利用方法

市役所健康課で申請し、施設予約を調整

## 問い合わせ

健康課母子健康係（電話0289-63-2819）
