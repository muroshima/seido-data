# 【新規受付終了】鹿沼市住宅リフォーム助成事業補助金

取得元の利用規約により本文は掲載せず、制度の情報だけを取り出しています。正確な内容は `url` のページで確かめてください。

## 対象者

市内住所者でリフォームを行う所有者または居住者

## 支援内容

リフォーム経費の10%以内（上限8万円）

## 利用方法

工事着手前認定申請が必要
