# 奥多摩町の子育てに関する相談（心理・発達相談）

## 概要

奥多摩町こども家庭センター「きこりん」では、臨床心理士による心理・発達相談を行っています。0 歳〜18 歳未満のお子さんの発達や心理相談等あらゆる相談に応じます。

## 対象者

0 歳〜18 歳未満のお子さん
子ども本人や、子育て中の家族

0 歳〜18 歳未満のお子さん

## 支援内容

臨床心理士による心理・発達相談

## 利用方法

必ずこども家庭センターに予約をしてからご利用ください。
